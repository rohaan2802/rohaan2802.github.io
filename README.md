# Mohammad Rohaan — Portfolio

Modern, fast, responsive personal brand website built for GitHub Pages.

## Run locally (debug)

**Requirements:** [Node.js](https://nodejs.org/) 18+

1. Open this folder in Cursor/VS Code.
2. Press **F5** (or **Run → Start Debugging**) and choose **Debug Portfolio (Chrome)** or **Debug Portfolio (Edge)**.
3. The dev server picks a free port automatically (prefers **8080**; frees it if busy, otherwise uses the next available port).
4. Your browser opens at the correct URL when the server is ready.

**Terminal only:**

```bash
npm run dev
```

Look for `SERVER_READY:http://127.0.0.1:PORT/` in the output and open that URL.

## Update content

- Edit `index.html` (copy, featured projects, links).
- Styles live in `style.css` (token-based design system).
- Resume PDF is at `resume/Mohammad_Rohaan_Resume.pdf`.
